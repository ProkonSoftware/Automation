Installing the PROKON Automation Host

The Automation Host is one program, prokon-automation.exe, that runs all the PROKON design engines. It works out of the box: it brings its own Python, already loaded with numpy, pandas, matplotlib and openpyxl.

Its main purpose is to let an AI assistant do PROKON design work for you. You describe the job in plain English ("size a pad footing for these column loads and show me the options as a chart") and the assistant calls the PROKON engines, or writes and runs a Python script that does. For that you need an agentic AI tool: one that can use tools and run programs on your PC, not just chat.

Step 1: Get an AI assistant (recommended)

Install one of these before you install the host. Setup then connects the host to it for you.

ToolCostWhere to get it
Claude Code (Anthropic)Paid: needs a Claude subscription or an Anthropic API account.claude.com/claude-code
OpenCodeFree and open source. It can use free AI models, or connect to paid ones.opencode.ai

Either works. Follow the tool's own install instructions, and start it once to sign in or set it up.

You can also use the host with no AI tool at all, to run your own Python scripts. See Running a script yourself.

Step 2: Install the host

  1. Run Install-Prokon-Automation-Host.exe. No administrator rights are needed.
  2. Choose the folder, or accept the default: C:\Users\<you>\.prokon\automation-host.
  3. Finish the wizard. Setup installs the host and its Python, then connects the host to every AI tool it finds: Claude Code, OpenCode, or both. The finish page tells you what happened for each one.
  4. Restart your AI tool (and any open terminal) so it picks up the new settings.
Installing or updating the host closes any copy of it that is running. An AI tool that was using it loses its PROKON tools until you restart that tool.

Installed your AI tool afterwards? Connect it later

Run this in PowerShell (change the folder if you installed somewhere else):

& "$env:USERPROFILE\.prokon\automation-host\prokon-mcp.cmd" register

Two more commands do the opposite and report the current state:

& "$env:USERPROFILE\.prokon\automation-host\prokon-mcp.cmd" unregister
& "$env:USERPROFILE\.prokon\automation-host\prokon-mcp.cmd" status

status lists each AI tool and whether PROKON is registered with it.

Using a different AI tool? Any tool that supports MCP (the standard way to give AI assistants tools) can use the host. Point it at this command:

C:\Users\<you>\.prokon\automation-host\prokon-automation.exe mcp-serve

Step 3: Check that it works

Open your AI tool and ask:

Using PROKON, what is the moment capacity of a 300 x 500 mm beam section to BS8110 - 1997,
with fcu 30, fy 450, fyv 450, 40 mm cover all round, M = 200 kNm and V = 100 kN?

It should report about 295.2 kNm. If the tool says it has no PROKON tools, run prokon-mcp.cmd status (above) and restart the tool.

Running a script yourself

The host can run any PROKON-Python script directly, with no AI tool involved:

& "$env:USERPROFILE\.prokon\automation-host\prokon-automation.exe" run my_script.py

Scripts are written exactly as described in Writing PROKON-Python scripts, and every script in the examples folder runs this way.

Using your own Python instead of the built-in one

By default the host runs scripts with the Python it installed, in the python folder inside its install folder. You might prefer your own Python: for example, to use extra libraries you have installed there. The host finds Python through an environment variable called PROKON_PYTHON, which setup points at its own Python.

The rules

  • Python 3.12, 3.13, 3.14 or 3.15, 64-bit. Older versions are refused with a message saying which versions are supported.
  • PROKON_PYTHON must name the folder that holds python.exe, not python.exe itself.
  • You do not need to install anything PROKON into your Python. The host supplies prokon.v5 to your scripts itself.
  • Your scripts can only use libraries installed in your Python. To run the examples, add the four they use: 
    "C:\path\to\your\python\python.exe" -m pip install numpy pandas matplotlib openpyxl

How to switch

  1. Find your Python's folder. For example, in a terminal: 
    python -c "import sys, os; print(os.path.dirname(sys.executable))"
  2. Set the variable for your user account in PowerShell, using that folder: 
    [Environment]::SetEnvironmentVariable("PROKON_PYTHON", "C:\path\to\your\python", "User")
  3. Restart your AI tool and any open terminals. Programs that were already running keep the old setting.

How to switch back

Point the variable at the host's own Python again:

[Environment]::SetEnvironmentVariable("PROKON_PYTHON", "$env:USERPROFILE\.prokon\automation-host\python", "User")
Re-installing or updating the host also sets PROKON_PYTHON back to the built-in Python. After an update, repeat the switch if you want to keep using your own.

Removing it

Use Settings → Apps → Installed apps and uninstall PROKON Automation Host. This also disconnects it from the AI tools that setup connected it to.
