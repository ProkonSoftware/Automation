Installing PROKON for Spyder

Choose this if you want something that works straight out of the box. Spyder is a free Python editor for scientists and engineers. It comes with its own Python and with the libraries the PROKON examples use (numpy, pandas, matplotlib and openpyxl). PROKON for Spyder adds one thing to it: the prokon.v5 Python package, which runs the PROKON design engines from your scripts.

What you need

  • A Windows PC.
  • Spyder 6, installed for your own user account (instructions below).
  • A PROKON licence for the engines you want to use, through the PROKON License Manager.
  • The installer file Install-Prokon-5-for-Spyder.exe.

You do not need administrator rights, and you do not need to install Python separately.

Step by step

  1. Install Spyder 6. Download the Windows installer from spyder-ide.org and run it.
    Install Spyder for yourself only (just for your user account), not "for all users". If Spyder is installed for all users, PROKON setup usually cannot write into it, and it will stop and tell you so. The reliable fix is to reinstall Spyder for yourself only.
  2. Close Spyder if it is open.
  3. Run Install-Prokon-5-for-Spyder.exe. Setup finds Spyder by itself. The last page before installing shows where it found it: 
    Spyder found at:
      C:\Users\<you>\AppData\Local\spyder-6
    If you have more than one Spyder installed, that page says so and names the one PROKON will go into.
  4. If PROKON for Spyder is already installed, setup asks whether to replace it. Yes removes the old copy completely and then installs the new one. No cancels and changes nothing.
  5. Wait for the self-check. At the end, setup runs every PROKON engine once and compares the answers with the ones recorded when the installer was built. This can take a minute.
  6. Read the finish page. It tells you which of these happened:
    The finish page saysWhat it means
    PROKON is installed and every engine was checked.You are ready.
    PROKON was installed successfully. Validation did not complete, because this computer has no PROKON licence…The install is fine; the check could not run. Sign in to the PROKON License Manager, then run Check PROKON engines from the Start Menu.
    The check did NOT pass.Send the report file named on the page to Prokon support.

Check that it works

Open Spyder and paste this into the editor, then press F5 to run it:

import prokon.v5

answer = prokon.v5.beam_section.analyse(
    design_code="BS8110 - 1997",
    m=200, v=100,
    bw=300, h=500,
    dc_t=40, dc_b=40, dc_s=40,
    fcu=30, fy=450, fyv=450,
)

print(answer["result"]["mu"])

It should print 295.18197048179997 (the section's moment capacity in kNm).

Run your scripts from inside Spyder

Spyder prepares its Python environment before it runs your script. If you start Spyder's python.exe directly from an ordinary command prompt instead, that preparation is skipped. Simple scripts still work, but scripts that draw charts with matplotlib can exit without any error message. Running the same script from inside Spyder works.

Removing it

Use Settings → Apps → Installed apps and uninstall PROKON 5 for Spyder. Spyder itself is left alone.
