Installing PROKON for VS Code

VS Code is "bring your own Python". Unlike Spyder, VS Code does not come with Python. You install Python yourself, add the libraries you want, and then PROKON setup installs the prokon.v5 package into the Python you choose.

This takes a few more steps than Spyder, and gives you full control over your Python. If you just want something that works straight away, use Spyder instead.

There are four parts: VS Code, Python, your project's environment and libraries, and PROKON.

Part 1: Install VS Code and its Python extension

  1. Download and install VS Code from code.visualstudio.com.
  2. Open VS Code, go to the Extensions view (Ctrl+Shift+X), search for Python (published by Microsoft) and install it. This one extension also brings in the Python language support (Pylance), the debugger and the environment manager.

Part 2: Install Python from python.org

  1. Go to python.org/downloads and download the current Python release for Windows (64-bit). PROKON needs Python 3.8 or newer; any current release is fine.
  2. Run the downloaded installer and follow its steps.
  3. Check it worked. Open a new terminal (in VS Code: Terminal → New Terminal) and type: 
    python --version
    You should see something like Python 3.14.0.
    If the Microsoft Store opens instead, Python is not installed yet (or the terminal was opened before you installed it). Windows has a built-in python shortcut that sends you to the Store when no Python is present. Close the Store, open a new terminal, and try again after finishing the python.org install.

Part 3: Create your project's environment and add libraries

A virtual environment (a "venv") is a private copy of Python for one project. Libraries you add go into that project only. This is the usual way to work in VS Code, and it is the recommended place to install PROKON.

  1. Make a folder for your scripts and open it in VS Code (File → Open Folder…).
  2. Create the environment. Either press Ctrl+Shift+P and run Python: Create Environment (choose Venv), or type this in the terminal: 
    python -m venv .venv
    This creates a .venv folder inside your project.
  3. Tell VS Code to use it: press Ctrl+Shift+P, run Python: Select Interpreter, and pick the one inside .venv.
  4. Add the libraries. PROKON itself needs nothing beyond plain Python. The examples, though, use four popular libraries for tables, spreadsheets and charts. Install them into your environment with: 
    .venv\Scripts\python.exe -m pip install numpy pandas matplotlib openpyxl
    numpyfast arrays and maths
    pandastables of results
    matplotlibcharts
    openpyxlreading and writing Excel files

    The same command adds any other library later: …python.exe -m pip install <name>. These libraries are your choice. PROKON setup never requires them, and installs fine without them.

You do not have to use a venv. You can install PROKON straight into the Python you installed in Part 2. Just remember that PROKON (like any library) is available only in the Python it was installed into.

Part 4: Install PROKON

  1. Find the path to your environment's Python. In the VS Code terminal, with your environment selected, run: 
    python -c "import sys; print(sys.executable)"
    For a project venv it ends in .venv\Scripts\python.exe. Copy it.
  2. Run Install-Prokon-5-for-VSCode.exe. No administrator rights are needed.
  3. On the page "Which Python should PROKON be installed into?", setup lists the Pythons it found on your PC. Nothing is pre-selected, on purpose: pick carefully.
    • If your Python is in the list, select it.
    • For a project venv (which a search of the PC cannot find), choose the last entry, "Choose a different interpreter, or a .venv in your project folder…", and paste the path you copied.
  4. Setup checks that Python before installing. If it cannot use it, it says why (for example, the file does not exist, the Python is older than 3.8, or it cannot write to that Python's library folder). Choose another, then continue.
  5. Finish the wizard.
One Python per PC. PROKON for VS Code lives in one Python at a time. If you later install it into a different Python, it is removed from the first one. If import prokon.v5 stops working in an old project, that is why: re-run setup and choose that project's Python.

Check that it works

Create a file called check_prokon.py in your project folder:

import prokon.v5

answer = prokon.v5.beam_section.analyse(
    design_code="BS8110 - 1997",
    m=200, v=100,
    bw=300, h=500,
    dc_t=40, dc_b=40, dc_s=40,
    fcu=30, fy=450, fyv=450,
)

print(answer["result"]["mu"])

Run it with the ▶ button at the top right of the editor. It should print 295.18197048179997. If you see No module named 'prokon', VS Code is using a different Python from the one you chose in setup: run Python: Select Interpreter and pick that one.

Installing for IT departments

Setup can run without any windows, naming the Python on the command line:

Install-Prokon-5-for-VSCode.exe /VERYSILENT /PYTHON="C:\path\to\python.exe"

Removing it

Use Settings → Apps → Installed apps and uninstall PROKON 5 for VS Code. Your Python and your other libraries are left alone.
